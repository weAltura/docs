## 🚀 Quick Start

1. **Setup Environment**: Follow [Getting Started Guide](./01-GETTING-STARTED.md)
2. **Configure Environment**: See [Environment Setup](./ENV_SETUP.md)
3. **Start Development**: Run `pnpm dev` to start services and development server

## 📖 View Documentation

### Web Interface

Start the documentation server:

```bash
pnpm docs:serve
```

Then open your browser at: **http://localhost:8080**

The web interface provides:
- 📱 Responsive design
- 🔍 Full-text search
- 📑 Auto-generated sidebar
- 🎨 Clean, elegant theme
- ⚡ Fast loading (no build step)
